# EISForge Literature Reviews Directory

This directory stores HTML-format literature review files generated by EISForge v2's extraction pipeline (`extract_papers.py`).

## Structure

```
reviews/
├── README.md          ← this file
├── review.html        ← place your review HTML files here
└── *.html             ← additional review files
```

## How to Add a Review File

1. Run the EISForge extraction pipeline to generate a `review.html` file.
2. Copy (or move) the file into this directory:
   ```bash
   cp /path/to/review.html eisforge/knowledge/data/reviews/review.html
   ```
3. Load the review data into EISForge:
   ```python
   from eisforge.knowledge.parse_review_html import ReviewHTMLParser

   parser = ReviewHTMLParser('eisforge/knowledge/data/reviews/review.html')
   records = parser.parse()
   print(f'Loaded {len(records)} paper records')
   ```

## File Format

Each `review.html` file contains structured tables with the following fields extracted from electrochemical papers:

| Field | Description | Example |
|---|---|---|
| `title` | Paper title | "Electrooxidation of 2-propanol on Pt, Pd and Au" |
| `doi` | Digital Object Identifier | `10.1016/j.elecom.2007.09.016` |
| `potentials` | Extracted potential values (V) | `0.3`, `0.66` |
| `unit_ref` | Potential reference electrode | `RHE`, `SHE`, `Ag|AgCl` |
| `current_densities` | Extracted current density values | `3.0 mA cm⁻²` |
| `tafel_slopes` | Tafel slope values (mV dec⁻¹) | `95`, `156`, `542` |
| `Rct` | Charge transfer resistance (Ω) | `142.93`, `285.98` |
| `context` | Sentence context from paper | Full sentence around the value |
| `flags` | Source flag (own/crossref/etc.) | `own`, `crossref` |

## Integration with `literature_engine.py`

The `literature_engine.py` in the parent directory can be extended to load review HTML files from this directory automatically. See `parse_review_html.py` for the parser module.

## Notes

- Files in `.gitignore` patterns (e.g. large binary PDFs) should **not** be placed here — only the extracted HTML review files.
- Review HTML files generated on different dates should be named with a date stamp, e.g. `review_2026-06-12.html`.
